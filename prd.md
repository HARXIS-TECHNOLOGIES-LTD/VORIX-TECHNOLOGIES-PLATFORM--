# PRD — Phase 1 MVP (AI-Powered Trust Foundation)

## 1) Background

African housing markets face critical trust and transaction challenges where property seekers encounter rampant scams, unverified listings, fragmented communication, and zero fraud protection. Traditional platforms offer listings without intelligence, leaving users vulnerable to sophisticated fraud schemes and wasting weeks searching through unverified properties. This Phase 1 MVP addresses the Product Charter's core problems through **AI-powered trust infrastructure** that eliminates fraud before users see it, matches properties intelligently based on behavior, and provides 24/7 conversational assistance. Unlike competitors who bolt-on features, **Haxis positions as Africa's first AI-powered trusted housing ecosystem** where every listing is verified by machine learning, every match is personalized through behavioral intelligence, and every conversation is protected by real-time scam detection. This iteration targets all four personas — Chioma (tenant), Adebayo (landlord), Fatima (agent), and Ibrahim (student) — focusing on rental properties while establishing the platform's AI-first credibility infrastructure. This is the right time because AI maturity enables fraud prevention at scale, behavioral matching accuracy exceeds human intuition, and African markets demand trust solutions that legacy platforms cannot provide.

**Value Proposition:** "HAXIS is Africa's AI-powered trusted housing platform that combines verified listings, secure communication, and intelligent automation to eliminate property scams and simplify housing management."

## 2) Objectives & Desired Outcomes

### Trust & Safety (AI-Driven)
- **95% fraud prevention rate**: AI catches suspicious listings before user exposure through image verification, document analysis, and pattern recognition, reducing scam reports to <1% (vs. 15-20% on competitor platforms)
- **90% user verification rate**: AI-assisted KYC completes in <10 minutes (vs. 24-48 hours manual review), removing friction while maintaining security
- **Trust index score 85+**: Users perceive platform as safest housing marketplace measured through quarterly confidence surveys

### Efficiency & Automation
- **80% faster property matching**: AI reduces search time from 2-3 weeks to 3-5 days by surfacing best-match properties proactively based on behavioral learning
- **70% communication automation**: AI-generated responses for routine landlord inquiries accelerate conversations without sacrificing quality
- **60% reduction in payment friction**: Smart reminders based on user behavior patterns (vs. generic calendar reminders) improve on-time payments

### User Experience
- **AI-personalized discovery**: Tenants immediately see "Best Match" properties with 90%+ relevance scores instead of browsing hundreds of irrelevant listings
- **24/7 AI assistance**: Every user has instant access to conversational AI that explains listings, compares properties, drafts messages, and guides first-time renters without human support bottlenecks
- **Proactive fraud protection**: Real-time scam detection in chat prevents users from sending money off-platform or falling for advance-fee schemes with instant intervention warnings

### Platform Differentiation
- **AI as core infrastructure**: Not "AI features" but AI-first architecture where trust scoring, matching, and safety are impossible without machine learning — creating defensible moat competitors cannot replicate
- **Behavioral intelligence**: Platform learns individual user patterns to predict needs, prevent risks, and optimize experiences automatically — becoming smarter with every interaction
- **Digital housing identity**: Trust scores and payment history create portable reputation system that unlocks better opportunities, lower rates, and priority access across ecosystem

### Business Growth (Year 1 Targets)
- **100,000+ verified users** with 95%+ passing AI verification
- **10,000+ verified listings** with AI authentication
- **$5M+ GMV** processed through platform
- **LTV:CAC ratio >3:1** through AI-driven retention and organic growth

### Non-goals / Boundaries
Phase 1 excludes savings features for rent renewals, group chats, shortlets, hostels, land transactions, payment pools, and advanced analytics to maintain focus on core AI trust engine, smart matching, basic AI assistant, and essential payment infrastructure with intelligent reminders.

## 4) Key Features

### AI Trust & Verification Engine (CORE DIFFERENTIATOR)

**Purpose:** Eliminate fraud through multi-layered AI validation that runs continuously across listings, users, and communications.

**Capabilities:**
- **Listing Verification:**
  - AI analyzes uploaded photos using reverse image search to detect stock images or stolen content
  - Computer vision evaluates image authenticity (lighting consistency, metadata GPS validation, architectural coherence)
  - NLP scans descriptions for scam keywords ("advance fee", "urgent payment", "Western Union")
  - Pricing anomaly detection flags properties 60%+ below market average as suspicious
  - **User Experience:** Only verified listings appear in search results; suspicious listings flagged for admin review instantly

- **User Risk Scoring (0-100 Trust Score):**
  - **Identity Verification (30%):** KYC completion, AI document authenticity check, biometric validation
  - **Platform Behavior (40%):** Payment reliability, communication quality sentiment analysis, dispute history
  - **External Signals (15%):** Phone legitimacy check, social media validation (optional LinkedIn/Facebook)
  - **Network Analysis (15%):** Connections to verified vs. flagged users, referral source trust inheritance
  - **Visible Trust Indicators:** Color-coded badges (🟢 High 80-100, 🟡 Medium 50-79, 🔴 Low <50) on all profiles and listings
  - **Real-time Updates:** Scores recalculate on every significant action (payment, message, review)

- **Communication Safety:**
  - BERT-based NLP classifier detects scam patterns in chat messages in real-time (<500ms latency)
  - **Intervention levels:**
    - Low risk (0-30): No action
    - Medium risk (31-60): Warning banner ("⚠️ Never send money outside Haxis")
    - High risk (61-85): Message held 30 seconds, strong warning both parties
    - Critical risk (86-100): Message blocked, admin review triggered
  - **Training data:** 50,000+ labeled messages (scams from fraud reports, public databases, synthetic generation)
  - **Accuracy:** 91% detection rate with 6% false positive rate (safety-first approach)

- **Transaction Monitoring:**
  - AI flags unusual payment patterns (amount anomalies, geographic inconsistencies, velocity checks)
  - Fraud alerts before suspicious transactions complete

**Technical Implementation:**
- Image verification: ResNet-50 CNN (94% accuracy, <2 sec inference on AWS Lambda)
- Document OCR: Google Cloud Document AI + Tesseract fallback
- Trust scoring: Weighted algorithm with real-time recalculation engine
- Scam detection: Fine-tuned BERT model with regex preprocessing
- Infrastructure: TensorFlow Serving on auto-scaling GPU clusters

### AI Smart Property Matching (CORE DIFFERENTIATOR)

**Purpose:** Replace manual browsing with intelligent discovery that learns user preferences and surfaces optimal properties proactively.

**Capabilities:**
- **Hybrid Recommendation Engine:**
  - **Collaborative filtering:** Matrix factorization learns from user-property interactions (views, saves, inquiries weighted differently)
  - **Content-based filtering:** Matches property features (price, location, amenities, landlord trust) to user preferences
  - **Contextual bandits:** Thompson Sampling balances exploration (new listings) vs. exploitation (proven matches)
  - **Cold start solution:** Onboarding quiz creates initial preference vector for new users

- **Best Match Ranking Algorithm:**
  ```
  Match Score =
    Relevance (40%): Budget + location + amenities alignment
    + Trust (30%): Landlord verification & rating history
    + Availability (15%): Timeline fit with user move-in date
    + Value (10%): Price competitiveness vs. market average
    + Urgency Fit (5%): Alignment with user's search intensity
  ```
  - **Display:** Top 3 results flagged as "Best Match" with explanations
  - **Transparency:** "92% Match: Perfect for your budget + trusted landlord + available immediately"

- **Intent Prediction:**
  - Random Forest classifier segments users (Student, Young Professional, Family, Expat) based on search patterns, budget behavior, time-of-day activity
  - Adjusts recommendations: Students prioritize price, Families prioritize space/schools, Professionals prioritize commute
  - **Accuracy:** 83% classification rate (sufficient for personalization)

- **Proactive Recommendations:**
  - Push notifications when new listings match saved searches
  - "Users like you also viewed these properties" collaborative signals
  - Price drop alerts on previously viewed properties

**Performance:**
- Pre-computed recommendations (nightly batch, Redis cache, <50ms API response)
- FAISS approximate nearest neighbors for "More Like This" queries
- A/B testing shows **2.3x better conversion** vs. non-AI recommendations

**Technical Implementation:**
- Collaborative: Alternating Least Squares matrix factorization (50 latent factors)
- Content: Weighted Euclidean distance with grid-search tuning
- Serving: TensorFlow Serving with load balancing, auto-scaling
- Storage: PostgreSQL (user interactions), Redis (recommendation cache)

## 10) Risks & Mitigation

### Technical Risks

**AI Model Accuracy:**
- **Risk:** False positives block legitimate listings, false negatives allow scams
- **Mitigation:** Human-in-the-loop for edge cases, continuous retraining, user appeal process
- **Target:** 95% accuracy, <3% false positive rate

**Scalability:**
- **Risk:** AI inference latency increases with user growth
- **Mitigation:** Pre-computation (nightly batch recommendations), caching, auto-scaling infrastructure
- **Monitoring:** Real-time latency dashboards, <2 sec response time SLA

**Data Privacy:**
- **Risk:** AI requires user data, potential breaches or misuse
- **Mitigation:** Anonymization, encryption, GDPR/NDPR compliance, transparent data policies
- **Governance:** Ethics committee, quarterly third-party audits

### Market Risks

**User Adoption:**
- **Risk:** Users resist verification requirements or distrust AI
- **Mitigation:**
  - Fast verification (<10 min AI-assisted) reduces friction
  - Transparent AI explanations ("Why we recommend this")
  - Social proof (testimonials, trust badges)

**Competitor Response:**
- **Risk:** Incumbents add AI features quickly
- **Mitigation:**
  - AI-first architecture = defensible moat (can't bolt on easily)
  - Network effects (trust scores, behavioral data) compound over time
  - Speed to market (first-mover advantage in AI trust)

**Regulatory:**
- **Risk:** AI regulations, data protection laws, housing regulations
- **Mitigation:**
  - Legal counsel in each market
  - Explainable AI (show how decisions made)
  - Proactive compliance (NDPR, KYC/AML)

### Operational Risks

**Quality Control:**
- **Risk:** AI makes mistakes, damages user trust
- **Mitigation:**
  - Graduated rollout (5% → 25% → 50% → 100%)
  - A/B testing all models before full deployment
  - Instant rollback capability for critical issues
  - Incident response protocol (<24 hour investigation)

**Dependency on Third Parties:**
- **Risk:** Google Cloud, payment gateways, KYC providers have outages
- **Mitigation:**
  - Multi-cloud strategy (AWS backup for critical services)
  - Multiple payment gateway integrations
  - Graceful degradation (core features work even if AI down)

**Bias & Fairness:**
- **Risk:** AI models discriminate against certain demographics
- **Mitigation:**
  - Diverse training data across income, language, location
  - Bias monitoring dashboards (performance by demographic)
  - External ethics audits quarterly
  - User feedback channels for reporting unfair treatment

```python
def calculate_trust_score(user):
    """
    Weighted trust score calculation (0-100 scale)
    """
    # Identity Verification (30%)
    identity_score = 0
    if user.kyc_completed:
        identity_score += 100 if user.document_ai_confidence > 0.9 else 50
    if user.biometric_verified:
        identity_score += 50
    identity_weight = min(100, identity_score) * 0.30

    # Platform Behavior (40%)
    payment_reliability = (user.on_time_payments / max(user.total_payments, 1)) * 100
    communication_quality = user.avg_message_sentiment_score * 100  # 0-1 scale
    dispute_penalty = max(0, 100 - (user.disputes * 20))
    platform_tenure = min(100, user.days_active / 3.65)  # 1 year = 100

    behavior_score = (
        payment_reliability * 0.4 +
        communication_quality * 0.3 +
        dispute_penalty * 0.2 +
        platform_tenure * 0.1
    )
    behavior_weight = behavior_score * 0.40

    # External Signals (15%)
    external_score = 0
    if user.phone_legitimate:
        external_score += 50
    if user.social_media_verified:
        external_score += 50
    external_weight = external_score * 0.15

    # Network Analysis (15%)
    verified_connections_ratio = (
        user.verified_connections / max(user.total_connections, 1)
    )
    network_score = verified_connections_ratio * 100

    if user.connected_to_banned_users:
        network_score -= 50  # Heavy penalty

    if user.referral_source and user.referral_source.trust_score > 70:
        network_score += user.referral_source.trust_score * 0.2  # Inherit 20%

    network_weight = max(0, min(100, network_score)) * 0.15

    # Total score
    total = identity_weight + behavior_weight + external_weight + network_weight

    # Penalties
    if user.active_disputes > 0:
        total -= user.active_disputes * 10
    if user.late_payments_last_6_months > 0:
        total -= user.late_payments_last_6_months * 5
    if user.flagged_messages > 0:
        total -= user.flagged_messages * 15

    # Final score (capped 0-100)
    final_score = max(0, min(100, total))

    return {
        'score': final_score,
        'breakdown': {
            'identity': identity_weight,
            'behavior': behavior_weight,
            'external': external_weight,
            'network': network_weight
        },
        'tier': get_trust_tier(final_score)
    }

def get_trust_tier(score):
    if score >= 80:
        return {'tier': 'HIGH', 'color': 'green', 'emoji': '🟢'}
    elif score >= 50:
        return {'tier': 'MEDIUM', 'color': 'yellow', 'emoji': '🟡'}
    else:
        return {'tier': 'LOW', 'color': 'red', 'emoji': '🔴'}
```

```python
def calculate_match_score(user, property):
    """
    AI-powered property matching score (0-100)
    """
    # Base similarity from ML models
    collaborative_score = get_collaborative_filtering_score(user, property)  # 0-1
    content_score = get_content_based_score(user, property)  # 0-1
    base_score = 0.6 * collaborative_score + 0.4 * content_score

    # Relevance (40% of total)
    budget_match = 1 - abs(property.price - user.avg_budget) / user.avg_budget
    location_match = calculate_location_similarity(user.preferred_locations, property.location)
    amenities_match = calculate_amenity_overlap(user.preferred_amenities, property.amenities)

    relevance = (budget_match * 0.5 + location_match * 0.3 + amenities_match * 0.2) * 0.4

    # Trust (30% of total)
    trust = (property.landlord.trust_score / 100) * 0.3

    # Availability (15% of total)
    availability = 0.15 if property.status == "Available" else 0
    if property.available_date <= user.move_in_date:
        availability *= 1.2  # Boost if timeline aligns

    # Value (10% of total)
    market_avg = get_market_average(property.location, property.type)
    price_diff = abs(property.price - market_avg) / market_avg
    value = (1 - price_diff) * 0.1

    # Urgency fit (5% of total)
    user_urgency = calculate_user_urgency(user.search_frequency, user.days_searching)
    property_urgency = 1 if property.days_listed < 7 else 0.5
    urgency = (user_urgency * property_urgency) * 0.05

    # Total score
    total = relevance + trust + availability + value + urgency

    # Penalties
    if property.days_listed > 60:
        total *= 0.9  # Stale listing
    if property.views > 1000 and property.inquiries < 10:
        total *= 0.85  # Low conversion (possible issue)

    # Scale to 0-100
    final_score = min(100, total * 100)

    return {
        'score': final_score,
        'explanation': generate_match_explanation(final_score, relevance, trust, availability),
        'breakdown': {
            'relevance': relevance,
            'trust': trust,
            'availability': availability,
            'value': value,
            'urgency': urgency
        }
    }
```
